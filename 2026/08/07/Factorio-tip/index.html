加了模组也能解锁成就方法

方法1

用GitHub上的oorzkws/FactorioAchievementEnabler(可直接搜索FactorioAchievementEnabler或者直接到这里)，下载下来version.dll并放到Factorio.exe旁边，在Steam里游戏的启动项填cmd /c start "" %command% -> 参考Github上的Readme即可
这个方法约等于一劳永逸,但游戏大更时有可能会失效,失效的话要重新下更新后的

方法2

手动把下载下来的mod移到官方mod/DLC旁边(data文件夹下)。这个方法是让它把mod当成了官方mod/DLC同等的存在，在data文件夹下把要用的mod放在base , core旁边 跟它们同级就行了，解不解压都行
MOD的默认存放路径为:C:\Users\你的用户名\AppData\Roaming\Factorio\mods
这个方法不受游戏更新影响(除非游戏更新专门让这个方法失效)，但是要更新mod的时候需要手动移动mod

杂项tip

  • 【插件塔】只能将效果分享给附近的非燃烧设备,并且只有带插件槽的机器才会受到插件塔的影响
  • 【传说首先】可以用Creative搓一个传说装甲出来 -> 复制箱不停品质回收就行
  • 【传说铁箱注意】只要是最终使用的成品,放到一个传说铁箱足够了(比如造出来的传说品质2,传说产能2,收集一箱子完全够了),要是中间产物缓冲用的再多摆箱子,要不就是纯粹的浪费
  • 【热量输出】供热塔和核反应堆其实输出热量相同,供热塔燃烧效率高(有能源的地方推荐这个),核反应堆有相连加成(这个造成2*2的4个一组效果最好)
  • 【核反应堆摆放++双行布局,以及换热器布局】最为有效的摆放方式是对齐双行摆放，数量任意 ; 紧密放置的核反应堆能获得毗连加成，没有加成的核反应堆可驱动四座换热器，每获得100%的毗连加成便可驱动额外的四座换热器
  • 【逐日者成就】仅使用太阳能板发电,每小时发电量达一百亿焦耳(10GJ) -> 指定电网内除了太阳能板外不能有其它发电设施 ; 1小时内产生10GJ电能所需的稳定功率为10GJ÷(60×60s)=2778kW。考虑昼夜交替因素，在新地星上太阳能板的平均发电功率为42kW，即理论上只需铺设67块太阳能板并保持满负载即可解锁本成就

星球相关

【融冰】这个可以上产能插件,这是在太空平台、雷神星和玄冥星上获取水的主要方式

火星

丢个核弹就可以炸出一个岩浆洞来(可以摧毁地块变成岩浆地,获得无限资源入口) -> 注意使用不当会玩死自己(切记!!!) -> 火星其实是鼓励用来升品质
【高架铁路可以跨越岩浆】
【生态环境,主要用于地图生成思路】祝融星有三种不同的生态系统： 1.灰烬高原 - 点缀着稀疏的植被和煤矿的高原，生长着没有叶子的外星树木，其中一些处于燃烧状态，在砍伐时会在周围生成一圈火焰。这一环境中悬崖和熔岩相对较少，非常适合建设。 ; 2.熔岩盆地 - 充满了蜿蜒的熔岩河流，其中蕴含钨矿，只能使用大型采矿机开采 ; 3.山脉 - 被悬崖地形覆盖的火山，中心有一个大型熔岩池，硫酸喷泉和方解石矿位于此处。

雷星

其实是鼓励火车连岛(高架铁路能直接上油海),即碎片化生产,然后用火车连接碎片化的产线 -> 所以一个岛做专一碎片化处理,然后火车转移输出,即一个岛最好只做一种事 -> Wiki上也说最好为每座岛屿建造独立的物流网络和电力系统
【闪电注意,一些东西免疫雷击】1.任何铁路轨道(普通铁轨和高架铁路)； 2.铁路信号设备(常规铁路信号和联锁铁路信号,注意不包括车站); 3.任何火车机车和车厢;
【废料回收思路】回收废料产生的12种物品中,其中3种只有单一的用途: 1.冰融化成水; 2.固体燃料用于和轻油制作火箭燃料; 3.钬矿用于和水、石矿制作钬溶液
【钬板可以在铸造厂造】可以吃到50%的产能加成 -> 雷星本地摇传说钬板+传说电磁工厂(电磁工厂造电磁工厂然后分解得到原材料) -> 传说钬板拉到火星做传说超导体,即可做传说品质3 + 传说低温工厂

火车信号学习 -> 信号灯的意义就在于防止撞车

【常规铁路信号】在铁路上放下后在该处将铁路分为前后两部分,平常是绿灯允许列车通过,若前面的部分有列车,则变成红灯,使后面的部分的列车在这个信号灯停下,避免撞车 -> 每一处常规铁路信号都会划分一处断点,常规铁路信号只读取它前面仅一个部分来决定是否红灯
【联锁铁路信号】1.一直向前读取到第一个常规铁路信号的状态,输出该状态(相当于前面第一个常规信号灯的指针),注意只读常规信号灯,会跨越联锁信号灯; 2.具有常规铁路信号的功能,即前面的部分有车,就变红灯; 3.蓝色状态,即前面部分有岔路(比如两条),两个分支的下一个常规铁路信号是一红一绿,这时候联锁铁路信号就会变成蓝灯,会允许往绿灯那边走的列车通过,让往红灯那边走的列车停下
【联锁铁路信号的意义】在双向交叉路口(划分为4个部分),只用常规铁路信号会导致该在路口外停车等待的列车进入路口里等待,导致死锁 -> 就是常规铁路信号会导致列车停在路口里导致堵车,因此需要把停车信号传递到路口外从而避免堵车死锁 -> 简单记忆的话就是入路口用联锁,路口中间用连锁,出路口用常规 -> 【GPT提示】联锁信号关心的是: 列车能不能沿着自己的路径穿过前面的区块,并最终到达一个允许它进入的出口区块,所以它最重要的思想是:我允许你进入这里的前提，是你能够从这里出去,即放灯时的问题:“这个地方允许火车停下来吗?”,如果不行会挡住其他车,那应该就是联锁信号灯,如果完全停在这也不会妨碍路口,那就用常规信号灯,即:常规信号：前面没车，你就可以进去 ; 联锁信号：前面不仅得能进去，而且你还得能出去，我才让你进去
【核心思路】拿起信号灯,看铁路上,相同颜色的部分只能存在一辆车,其余列车会被红灯拦下等待

草星

溢出的变质物/种子不仅是回收机,还有丢供热塔燃烧(这个是推荐销毁路径) ; 铜铁矿只能回收机销毁了,两个回收机对着,爪子抓进去那个只要1个速度3就够,剩下全上节能2 , 另一个只放两个节能2降到20%上限即可 【关键是环带】想不明白就上巨大环带,可以优雅处理副产物(种子和变质物)+产线永远不堵
【关于营养素】++的配方为组装机3变质物制营养素(单输入单输出,便捷冷启动) ; 两种果子制营养素(产线特别复杂但产量巨大)
【供热塔的250%效率,处理废弃可燃物】供热塔的效率为250%指的是它能产生其所消耗燃料热值2.5倍的热能 -> 不过供热塔输出恒定,因此因此供热塔与换热器的最优比例固定为1:4 -> 在达到最高温度后，供热塔仍会继续消耗燃料，这使得供热塔拥有一个额外用途：处理废弃的可燃物品(例如句芒星生产的生物制品和变质物，或雷神星上生产的多余固体燃料)
【种植土】沃土对种植地格没有额外加成，而且它们比人造土贵得多，因此，应注意尽量少使用较昂贵的沃土，多用较便宜的人造土就可以了

太空平台

上高品铸造厂,不要炉子 ; 电力用普通的2台聚变核+8台普通聚变发电机+2台传说低温工厂弄氟酮够了,不需要储液罐,低温工厂的格子存足够了 ; 守船头的话机枪炮塔(造穿甲弹匣)、火箭弹炮塔都传说,磁轨炮用普通和传说交替(防止漏网之鱼),守两侧就是普通品质炮塔即可 ; 要安全就把引擎弄到最少,用1-2个 ; 就炸药在低温工厂造,其他的用那个化工厂就行(能传说就传说)
【Wiki】与从地面向太空平台运送物资不同，从太空平台向星球投送物资无需花费任何原料(尽管使用了着陆货舱) ; 当推进器因为各种原因在航线中途停车时，太空平台仍将受到行星引力的影响，缓慢地向距离其最近的星球移动(得有推进器之后才会因为熄火缓慢移动)
【太空可获得的资源】氧化星块获取水(融冰)/方解石 ; 金属星块获得铁矿/铜矿 ; 碳质星块获取碳(可转化为煤)/硫磺 ; 煤炭可液化为重油,做石油制品 【无法获得石矿】

冰星

地下传送带/地下管道的热能消耗要远大于地面铺设的普通传送带/管道 ; 还有插件塔也消耗大量热能
热管不会散失热量到环境中，只有与之相邻的建筑物会消耗热能 -> 热管可以远距传输热力,热管的热能容量是1MJ/度，所以在从500°C升到1000°C的过程中他们可以缓存500MJ的热能，使得其可以作为一种较为节省空间的能量存储设施。不过，温度在“传递”之前需要至少相差1度，因此你无法将其全部升至1000度或者降至500度
所有燃烧设备和供热设施(例如供热塔)不受冻结效果影响
当建筑物与热源相距一格以内，无论是从正面还是对角线方向，它都被视为与热源相邻并能接受供热
【聚变发电最优配置公式】最优发电机数量 = 2*(反应堆数量 + 所有反应堆享受的毗连加成之和(取整数))

看性能

按F4,里面找FPS/UPS相关的开关,应该是第一个 ; FPS是画面帧率,代表显卡压力 , UPS是游戏逻辑更新速度,代表CPU单核压力,默认在60UPS就没问题
地图非必要就少开 -> 最好别用Creative里的超级雷达二,用超级雷达那么大的地方完全够了
想要大箱子就用货车车厢 ; 汽车和坦克有额外UPS开销 ; 火箭发射井有可能会扰乱太空平台互动

记品质,传说相关产线思路

  • 【最关键的机制】液体没有品质+无插件时产出品质=输入品质,因此含有 : 液体+单个固体输入+回收出液体对应的固体(比如进去熔融铜回收出铜板的浇筑轻质框架配方)的配方适合大量造传说,所以++铸造厂配方,并且++高产能、多插槽建筑
  • 【注意】速度插件会减品质概率
  • 需要做传奇的基础材料 : 铁、铜、钢、塑料(其实就是传说煤)、石头

传说铁

就用铁矿就行(地星),注意品质不够的做成铁箱再分解 ; 火星用浇筑地下管道,先浇筑出管道,各种品质管道+熔融铁造地下管道(注意这里双排铸造厂把熔融铁输出一条在中线供应两端即可,每一边比例:管道:普通地下:绿色地下:蓝色地下:紫色地下=10:2:1:1:1),地下管道全部品质回收(不用判传说)出管道和铁板,管道品质不够的回流,传说的直接拿去分解出传说铁板,铁板传说的直接输出,品质不够的做成铁箱再升一次品再回收,是传说的输出,回收出品质不够的铁板回流做箱子 -> 【铁板做铁箱再回收是纯赚】无额外材料损耗+增加了一次品质判定次数

传说煤,塑料,巨额稳定铜+钢

传说煤用品质矿机+直接进回收机弄出传说煤最优,传说煤变传说塑料,传说塑料在铸造厂浇筑出传说轻质框架,传说轻质框架回收出传说铜+传说钢+传说塑料,传说塑料回流循环(塑料吃轻质框架300%产能再回收后,相当于催化剂,不消耗了)【所以传说铜/钢相关别上产能插件了,产量太大了消耗不掉,设计传说铁板的再上产能】 -> 为什么不先造塑料后循环塑料?:把"升品质的损耗"全部转嫁到最便宜的原料(煤)身上 : 首先回收机每次循环都要损失75%的材料,让煤承受这个损失比让塑料承担便宜得多,塑料是二次加工品,回收塑料其实还损失了机器产能 ; 化工厂不需要品质插件了,可以换成产能插件,这是纯赚

传说方解石,石砖

先转出传说方解石,在火山用方解石+岩浆->石头+熔融铁来搞,然后把熔融铁造成铁棒(这个最快)丢回岩浆,然后石头烧成石砖 -> 【所以建议火山星开传说】因为多液体配方+岩浆丢东西高效丢垃圾

传说蓝板,传说绿板+红板

想办法把蓝板产能科技点到+250%,这样配合电磁工厂的默认+50%产能就能达到300%产能上限,配合回收机,无损将所有输入蓝板变传说蓝板 -> 最后输出还是输出传说绿板+传说红板比较好 -> 【避免堵塞思路】内部传送带循环,然后在蓝板入口处用普通爪子往里夹普通蓝板(这样就是等循环回来的蓝板有空位了,才会夹新的进去,不会堵塞),绿板和红板也都要环线,用爪子不要筛选往电磁工厂里夹就行了(其实就是只要在处理这么四条线:绿板非传说回流,绿板传说输出,红板非传说回流,红板传说输出)

原矿硬转

矿机也支持品质插件,可以大矿机硬挖+品质回收机硬拉(注意品质矿机会减速度,计算的时候记得考虑进去 ; 还有一条带在大矿机25/s的时候,一条带4个大矿机一边2个足够了,太多了会堵塞产线导致停滞),但是效率很低,只适合启动

传说之后

  • 【造出传说后】能上产能建筑就上产能建筑(铸造厂、电磁工厂都有50%额外产能且可无脑替代原配方,生物室虽然也有额外产能但可以不换),产能插件能上就上/槽位多的建筑(低温工厂8个槽,注意产能最高300%),不用回收机(75%损失,太浪费,回收机不升品)

  • 【火星本地能造的有用传说】首先是传说的品质插件2(提升品质概率,一切的基础) ; 传说的集装机械臂、加长机械臂 ; 传说钢箱(容量2.5倍) ; 传说太阳能板/蓄电器(太空平台用) ; 传说组装机/化工厂/铸造厂/低温工厂(都是速度变2.5倍,用于太空平台) ; 插件塔(不光提效还减能耗)/各种传说插件2,重要,效率极大提升 ; 传说星岩抓取臂(全方位提升,重要)/破碎机(速度*2.5,用于太空平台)/货仓(增多格子) ; 传说炮塔,机枪炮塔、火箭炮塔(都只加射程,+50%) -> 造传说铸造厂会需要传说碳化钨,同时可量产传说速度3(火星本地即可完成)

  • 【特别注意】百科里物品是有回收配方的,这个是放入回收机到底出来什么,看清楚了再规划产线 -> 回收机可以上品质,回收是自己的话可以不停循环回收升品

  • 【品质物品tip】矿机品质只减资源消耗,不加挖矿速度 ; 传送带相关和管道的品质都没用(传送带堆叠后的运输数据就用最大堆叠数*传送带速度)
