去德国香港的准备

亲属关系证明

  • 亲属关系证明+海牙认证需要在户口所在地办，准备好材料就行
  • 河南省郑州市黄河公证处
  • 需不需要本人到场还有材料啥的不同公证处有区别的,多问几家
  • 办完邮寄即可

公章注意

如果是要开假条啥的，但是是个人私事，项目和学校无关的，这种不能盖学校公章。
私事盖不了公章，只能让领导签个名啥的。

欧元相关

去之前预约，但是预约多少欧和能取多少欧似乎无关(最后取了600欧)
拿身份证和银行卡就行，不用签证
换出来的都是200欧的纸币
换回人民币只收纸币，硬币不要。注意纸币不能有太大的破损，要不收不了。

插头和订酒店

订酒店直接携程上订即可 ; 去欧洲插头要买转换插头德标(两个圆孔)

几句常用德语如下：

你好：Hallo，Ha重读。
谢谢：Dankschön
execus me:Entschuldigung，en-chu-di-gung
不用谢：Bittschön
再见：Aufwiedersehen，后缀sehen读Zain

去VFS站点：大连北站–沈阳站

VFS离沈阳站很近，到沈阳站比较方便，从东广场出。
回来可以原路，沈阳到大连北有比较晚的车。
从大连北站出来回开发区校区：南广场出来，走地铁站地下通道到大路对面再打车，一定不要坐主动找的打表，公交或网约均可

去VFS不让用电脑，所以不要再带笔记本了！

提交补充材料不用排队，可以找人代办，直接过去现场提交就行了。

办港澳通行证预约

wx小程序移民局12367 -> 户籍所在地选身份证上的地区 -> 通行证和签注一起办,取证方式建议邮寄 ; 护照和通行证都办的话邮寄是同一个快递寄过来 ; 签注是有自助机"智能签注设备"的,可以直接自己来办签注
物理前往: 高铁直达 ; 飞深圳后高铁香港,深圳到香港只需20m高铁
买境外流量包,去运营商搜"国际",购买后进香港之前去设置 -> SIM卡 -> 开启漫游 ; 还有联通去搜索"跨境语音和短信"打开国际短信
【符号】在香港本地,符号$就表示港元
众安za bank,是数字银行,没有线下实体网点一切都在APP进行(在香港下载),入金走跨境支付通很简单,能绑微信支付宝和applePay,但出金只能用wise汇款,实测往内地转1w转到zfb手续费是160转到银联260
开户需要:18岁+ ; 在香港境内 ; 身份证 ; 通行证 ; 内地手机号 ; 和内地手机号绑定的银行卡 ; 需要在主城区内开户 ; 可724小时申请,5个工作日内完成审核 ; 手机NFC ; 填的时候职业信息开户目的都如实填写 ; 登记转数快打开,这样在香港银行之间用手机号就能汇款 ; 到等待审核中那里要继续开立投资账户、基金账户两个
【注意】需要买转换插头(英制),搜香港转换插头 ; 酒店在携程上订即可 ; 地铁可以用zfb的出行,城市选香港,是自动换成RMB扣zfb的钱的 ; 付款就用zfb或wx(就说中文),带一个人的话一个人刷wx另一个刷zfb就行(wx是小程序搜"地铁") -> 取港元纸币建议在深圳的地铁站/高铁站的货币兑换点换个几百RMB的港币,什么零钱都换的出来(甚至有1元钢镚)
内卡往港卡免手续费汇:内卡APP首页 -> 转账汇款 -> 跨境汇款 -> 下方"跨境支付通" -> 收款账号+姓名去港卡对应APP找/或者用香港的转数快直接内地电话号转【注,这个只能内卡和港卡同名才能免手续费,且单笔最多1w一天基本上最多3笔】,要转大额就走普通电汇,手续费转越多越划算
众安是自带券商投资功能的,不过得到香港才能办下来
【千万别直接用ZA的卡和国内地址去OpenAI官网填信息!!】用国内地址必定无法购买所选订阅内容,OpenAI明确写过,购买只在其支持的国家和地区提供,付款卡也必须由支持地区的银行发行 -> 去找美国地址生成器,就生成一个免税地址(一般来说交税并不能带来额外的消费保护和权益,也改变不了账号合法性,只是徒增成本,所以就走免税州好了,注意尽量不要阿拉斯加,只要美国本土4个常用免税州),注意账单姓名尽量和银行卡持卡人一致 -> 修改地址得修改法定地址*!!在Google个人资料,个人信息,其他地址,找到法定地址,改这个才有用 -> 改走App内订阅,如果你通过iOS或Android App订阅，账单将由Apple App Store或Google Play管理,并以本地货币显示(GPT图标变灰,去Google Play的设置的"账号和设备偏好设置"里把Play商店的钱包设置成美国,就是转成美区Google Play) -> 订阅只在你购买的平台管理:Google Play买的,就去Google Play取消;App Store买的,就去iPhone设置里的订阅取消;网页买的,就去ChatGPT网页端取消;要买一个月的就直接订阅,付一次费然后立刻取消订阅就行
【往Schwab弄需要wise】从ZA的app里直接往wise里海外汇款即可,账户详细信息看美元账户的那个信息来搞就行 -> 这里全程用真实地址和真实信息没问题 -> 账户类型在wise上看清楚,应该是checking -> Schwab上地址写的太长会导致wise账号弄不进去,把个人信息的地址改成短就可以了,能缩写全用缩写,比如Room用RM,Street用ST,这样后台不用二次验证,更改完马上能绑定新账户
