Factorio tip

Factorio

拒绝折磨创建地图设置

资源全部拉满
雷星岛屿设置拉满,最大化岛屿面积,方便布置产线 ; 岩石,树木,悬崖全部取消 ; 水域/岩浆可以弄少,用Waterfill模组造水坑,火星核弹炸岩浆坑
虫子全取消,没有敌人+和平模式,虫族扩张和进化因子也都取消
污染关掉,星岩生成速率适当调低(比如50%) , 变质速率直接拉到最低(10%),直接拒绝折磨

加了模组也能解锁成就方法

方法1

用GitHub上的oorzkws/FactorioAchievementEnabler(可直接搜索FactorioAchievementEnabler或者直接到这里)，下载下来version.dll并放到Factorio.exe旁边，在Steam里游戏的启动项填cmd /c start "" %command% -> 参考Github上的Readme即可
这个方法约等于一劳永逸,但游戏大更时有可能会失效,失效的话要重新下更新后的

方法2

手动把下载下来的mod移到官方mod/DLC旁边(data文件夹下)。这个方法是让它把mod当成了官方mod/DLC同等的存在，在data文件夹下把要用的mod放在base , core旁边 跟它们同级就行了，解不解压都行
MOD的默认存放路径为:C:\Users\你的用户名\AppData\Roaming\Factorio\mods
这个方法不受游戏更新影响(除非游戏更新专门让这个方法失效)，但是要更新mod的时候需要手动移动mod

杂项tip

  • 【传说首先】可以用Creative搓一个传说装甲出来 -> 复制箱不停品质回收就行
  • 【传说铁箱注意】只要是最终使用的成品,放到一个传说铁箱足够了(比如造出来的传说品质2,传说产能2,收集一箱子完全够了),要是中间产物缓冲用的再多摆箱子,要不就是纯粹的浪费
  • 【热量输出】供热塔和核反应堆其实输出热量相同,供热塔燃烧效率高(有能源的地方推荐这个),核反应堆有相连加成(这个造成2*2的4个一组效果最好)

星球相关

火星

丢个核弹就可以炸出一个岩浆洞来(可以摧毁地块变成岩浆地,获得无限资源入口) -> 注意使用不当会玩死自己(切记!!!) -> 火星其实是鼓励用来升品质

雷星

其实是鼓励火车连岛(高架铁路能直接上油海),即碎片化生产,然后用火车连接碎片化的产线 -> 所以一个岛做专一碎片化处理,然后火车转移输出,即一个岛最好只做一种事

草星

溢出的变质物/种子不仅是回收机,还有丢供热塔燃烧(这个是推荐销毁路径) ; 铜铁矿只能回收机销毁了,两个回收机对着,爪子抓进去那个只要1个速度3就够,剩下全上节能2 , 另一个只放两个节能2降到20%上限即可 【关键是环带】想不明白就上巨大环带,可以优雅处理副产物(种子和变质物)+产线永远不堵

太空平台

上高品铸造厂,不要炉子 ; 电力用普通的2台聚变核+8台普通聚变发电机+2台传说低温工厂弄氟酮够了,不需要储液罐,低温工厂的格子存足够了 ; 守船头的话机枪炮塔(造穿甲弹匣)、火箭弹炮塔都传说,磁轨炮用普通和传说交替(防止漏网之鱼),守两侧就是普通品质炮塔即可 ; 要安全就把引擎弄到最少,用1-2个 ; 就炸药在低温工厂造,其他的用那个化工厂就行(能传说就传说)

看性能

按F4,里面找FPS/UPS相关的开关,应该是第一个 ; FPS是画面帧率,代表显卡压力 , UPS是游戏逻辑更新速度,代表CPU单核压力,默认在60UPS就没问题
地图非必要就少开 -> 最好别用Creative里的超级雷达二,用超级雷达那么大的地方完全够了
想要大箱子就用货车车厢 ; 汽车和坦克有额外UPS开销 ; 火箭发射井有可能会扰乱太空平台互动

记品质,传说相关产线思路

  • 【最关键的机制】液体没有品质+无插件时产出品质=输入品质,因此含有 : 液体+单个固体输入+回收出液体对应的固体(比如进去熔融铜回收出铜板的浇筑轻质框架配方)的配方适合大量造传说,所以++铸造厂配方,并且++高产能、多插槽建筑
  • 【注意】速度插件会减品质概率
  • 需要做传奇的基础材料 : 铁、铜、钢、塑料(其实就是传说煤)、石头

传说铁

就用铁矿就行(地星),注意品质不够的做成铁箱再分解 ; 火星用浇筑地下管道,先浇筑出管道,各种品质管道+熔融铁造地下管道(注意这里双排铸造厂把熔融铁输出一条在中线供应两端即可,每一边比例:管道:普通地下:绿色地下:蓝色地下:紫色地下=10:2:1:1:1),地下管道全部品质回收(不用判传说)出管道和铁板,管道品质不够的回流,传说的直接拿去分解出传说铁板,铁板传说的直接输出,品质不够的做成铁箱再升一次品再回收,是传说的输出,回收出品质不够的铁板回流做箱子 -> 【铁板做铁箱再回收是纯赚】无额外材料损耗+增加了一次品质判定次数

传说煤,塑料,巨额稳定铜+钢

传说煤用品质矿机+直接进回收机弄出传说煤最优,传说煤变传说塑料,传说塑料在铸造厂浇筑出传说轻质框架,传说轻质框架回收出传说铜+传说钢+传说塑料,传说塑料回流循环(塑料吃轻质框架300%产能再回收后,相当于催化剂,不消耗了)【所以传说铜/钢相关别上产能插件了,产量太大了消耗不掉,设计传说铁板的再上产能】 -> 为什么不先造塑料后循环塑料?:把"升品质的损耗"全部转嫁到最便宜的原料(煤)身上 : 首先回收机每次循环都要损失75%的材料,让煤承受这个损失比让塑料承担便宜得多,塑料是二次加工品,回收塑料其实还损失了机器产能 ; 化工厂不需要品质插件了,可以换成产能插件,这是纯赚

传说方解石,石砖

先转出传说方解石,在火山用方解石+岩浆->石头+熔融铁来搞,然后把熔融铁造成铁棒(这个最快)丢回岩浆,然后石头烧成石砖 -> 【所以建议火山星开传说】因为多液体配方+岩浆丢东西高效丢垃圾

传说蓝板,传说绿板+红板

想办法把蓝板产能科技点到+250%,这样配合电磁工厂的默认+50%产能就能达到300%产能上限,配合回收机,无损将所有输入蓝板变传说蓝板 -> 最后输出还是输出传说绿板+传说红板比较好 -> 【避免堵塞思路】内部传送带循环,然后在蓝板入口处用普通爪子往里夹普通蓝板(这样就是等循环回来的蓝板有空位了,才会夹新的进去,不会堵塞),绿板和红板也都要环线,用爪子不要筛选往电磁工厂里夹就行了(其实就是只要在处理这么四条线:绿板非传说回流,绿板传说输出,红板非传说回流,红板传说输出)

原矿硬转

矿机也支持品质插件,可以大矿机硬挖+品质回收机硬拉(注意品质矿机会减速度,计算的时候记得考虑进去 ; 还有一条带在大矿机25/s的时候,一条带4个大矿机一边2个足够了,太多了会堵塞产线导致停滞),但是效率很低,只适合启动

传说之后

  • 【造出传说后】能上产能建筑就上产能建筑(铸造厂、电磁工厂都有50%额外产能且可无脑替代原配方,生物室虽然也有额外产能但可以不换),产能插件能上就上/槽位多的建筑(低温工厂8个槽,注意产能最高300%),不用回收机(75%损失,太浪费)

  • 【火星本地能造的有用传说】首先是传说的品质插件2 ; 传说的集装机械臂、加长机械臂 ; 传说钢箱(容量2.5倍) ; 传说太阳能板/蓄电器(太空平台用) ; 传说组装机/化工厂/铸造厂/低温工厂(都是速度变2.5倍,用于太空平台) ; 插件塔(不光提效还减能耗)/各种传说插件2,重要,效率极大提升 ; 传说星岩抓取臂(全方位提升,重要)/破碎机(速度*2.5,用于太空平台)/货仓(增多格子) ; 传说炮塔,机枪炮塔、火箭炮塔(都只加射程,+50%)

  • 【特别注意】百科里物品是有回收配方的,这个是放入回收机到底出来什么,看清楚了再规划产线 -> 回收机可以上品质,回收是自己的话可以不停循环回收升品

  • 【品质物品tip】矿机品质只减资源消耗,不加挖矿速度 ; 传送带相关和管道的品质都没用(传送带堆叠后的运输数据就用最大堆叠数*传送带速度)

HTTPS,TLS核心汇总

HTTP协议的问题

HTTP是你和服务器的通信是明文的,意思就是你上网链路上任何一个中间人都可以看到并修改你和服务器之间的通讯信息,比如运营商可以随意在你网页里插入广告
为了解决上面这个问题,就有TLS协议,就是非对称加密,私钥公钥这些

一句话总结TLS真正要解决的问题

如何在网络上发给对面密码,同时只有你最终要给的那个人知道密码是啥,其他网络中间层都得不到?

数据库MySQLRedis相关

高并发系统全景图(是靠分层削峰的)

用户 -> Cloudflare/CDN（抗流量洪峰）-> Nginx（入口并发 + 限流） -> Spring Boot（业务并发）-> Redis（高并发数据）-> MySQL（最终数据）
【Redis的核心价值】就是抗高并发,但不是取代MySQL,而是搭配使用
MySQL是关系型数据库,数据存磁盘,速度慢并发有限(磁盘IO拖累/锁竞争严重/写操作互斥)但是持久化;Redis属于内存数据库,数据存内存,速度快并发强,是极快的单线程,但持久能力有限,特别适合【读多写少,计数,状态判断】,用于【抢课名额,秒杀库存,登录状态,验证码】
【但是不能只用Redis】Redis内存有限,数据会丢,不适合复杂查询和长期存储;一般是Redis抗并发,MySQL存最终结果,
