## 基础饮食tip
- 外卖的健康度--,馋了尽量【线下店】或【自己做】一顿只吃肉买8两已经能吃的很饱了,1斤能撑的不行,要还弄点菜的话6两肉就够了 ; 偶尔放纵外卖快餐>泡面,快餐(尽量不点炸鸡,少点酱)更像一顿饭,--泡面(钠含量极高,吃完多喝水当天别再吃咸的);养人:蔬菜、水果(注意--果汁而是++直接吃完整的水果,苹果(JD,山东烟台栖霞红富士5斤85mm,大概8-9个,一天2个的话再买多后面会放坏))(减油盐糖,粥算高糖但温和可以偶尔吃,蜂蜜也算高糖--蜂蜜/蜂蜜水) ; --海鲜(三鲜也是海鲜要--),--油腻(如肘子,太油的炸蛋) ; 【尽量】水/蒸/煮/清炖/焯优先,剩下就往少油盐糖的方向去选
- 【GPT】大豆高蛋白(蛋白质主力)+补钙/铁+健康脂肪,豆制品算健康食物,豆腐,豆干(包装的也可以,但要原味/清淡的),豆皮(千张),腐竹,豆浆【注意面筋是面粉弄的,要减】 ; 要蛋白还有鸡蛋(高蛋白+全面营养,煎蛋比不吃蛋好,尽量少油且别煎太焦,包装的卤蛋也可以)+肉类(得是瘦肉/鸡肉/牛羊肉,清淡做法,还有++鸡胸肉) ; 大米/小麦(面粉)主力是碳水,也得有但别只有这些,友好是米饭+菜+豆制品,纯土豆粉/面条缺蛋白蔬菜那种就不推荐 ; 黑芝麻是健康的,但黑芝麻汤圆已经是甜点级了,高糖高油 ; 作息尽量不晚于12点,稳定睡眠
- 【在外选择原则】:主食+蛋白+蔬菜,少油少加工:外卖选盖饭(有肉有菜)轻食(鸡肉/牛肉+菜) ; 小店选面馆,加蛋+加青菜,盖饭选清淡点的肉 ; 实在没时间可以买两个茶叶蛋+一份简单主食
- 【*ys农业*】建议一般人健康饮食:减油,增豆(++大豆),加奶(++钙和蛋白质,++酸奶)
- 【菌类】常见为金针菇,杏鲍菇(有点粗长的白色那种),热量低+助消化+增鲜,没啥营养(不能当主力营养来源)但算很不错的配菜,因为增鲜能让少放油盐 -> 其实不只上面这几种,还有好多,正规餐馆和超市里的菌类都没问题
- 【CoachGreg】减肥不是米饭，香蕉，鸡蛋，牛排的问题 ; 是薯片，冰激凌，饮料，饼干，糖果，披萨，奶茶，火锅，烧烤!! -> 蔬菜和水果最有助于减肥
- 【圆脸】说泡药杨梅:杨梅草莓桑葚这些外皮脆弱运输损耗很重的多多少少都会有防腐剂 ; 苹果桃子这些是有外皮保护的,橘子这种更甚,这些保护期都很好
- 【260824甲醛白菜】白菜秋冬季节才收,并且整改?2012都报道过了 -> 所以--白菜 -> 还有带鱼,鱿鱼,都会有甲醛防腐,要-- -> 【王j】食品伦理破坏,破坏市场经济的基础,侵害人与人之间最基本的信任 -> 食监尸位素餐,王j曾经还在焦点访谈工作的时候还能曝光一些东西,但是现在 -> 没有触及上层,所以没有高压线,空气治理可见一斑
- 【偏口鱼博士】什么东西你能天天吃才是好东西,鸡蛋、胡萝卜、空心菜能天天吃,算好东西 -> 这些离老百姓近的,国家优先供应,价格低 -> 肉蛋奶,还有大豆
- 对于甜水,代糖饮料,该享受享受该克制克制,适度享受没问题251222周1-2次【水果医生】 -> 但日常还是水为主
- 【水果医生】见到年轻的脑干出血全都是长期血压高+大量饮酒 -> 治的话最好也就是植物人

## 想吃大量豆皮,和GPT讨论
需要: 宿舍小电锅(先不要蒸笼)、泡面碗、一次性筷子、洗洁精
番茄豆皮小火锅 = 番茄锅底 + 大量豆皮 + 鸡蛋 + 一种青菜 + 芝麻酱
【采购】不用去火锅超市,去附近的普通生鲜超市/菜市场最合适,因为核心材料豆皮、鸡蛋、青菜，普通生鲜超市更便宜
【鸡蛋处理】煎蛋反而意味着:要额外用油;锅更难洗;宿舍里油烟更麻烦;最后还得煮火锅 -> 水煮荷包蛋: 水和番茄锅底煮开 → 调到别沸腾得特别猛烈 → 鸡蛋直接磕进去 → 先别搅 → 蛋白定型以后继续煮熟
【GPT建议加菜】油麦菜 / 生菜 / 小白菜 / 菠菜，挑个喜欢的弄一把加进去，全手撕即可 -> 后面要再升级就再加100g左右鸡胸肉/瘦肉/鱼片都行
【清洗】没有煎炒产生的顽固油垢的话，完全可以不要海绵，手洗然后用纸擦干净即可
