## 拒绝折磨创建地图设置
资源全部拉满
雷星岛屿设置拉满,最大化岛屿面积,方便布置产线 ; 岩石,树木,悬崖全部取消 ; 水域/岩浆可以弄少,用`Waterfill`模组造水坑,火星核弹炸岩浆坑
虫子全取消,没有敌人+和平模式,虫族扩张和进化因子也都取消
污染关掉,星岩生成速率适当调低(比如`50%`) , 变质速率直接拉到最低(`10%`),直接拒绝折磨

### 方法1
用GitHub上的`oorzkws/FactorioAchievementEnabler`(可直接搜索`FactorioAchievementEnabler`或者直接到[这里](https://github.com/oorzkws/FactorioAchievementEnabler))，下载下来`version.dll`并放到`Factorio.exe`旁边，在Steam里游戏的启动项填`cmd /c start "" %command%` -> 参考Github上的Readme即可
这个方法约等于一劳永逸,但游戏大更时有可能会失效,失效的话要重新下更新后的

### 方法2
手动把下载下来的mod移到官方mod/DLC旁边(`data`文件夹下)。这个方法是让它把mod当成了官方mod/DLC同等的存在，在`data`文件夹下把要用的mod放在`base , core`旁边 跟它们同级就行了，解不解压都行
MOD的默认存放路径为:`C:\Users\你的用户名\AppData\Roaming\Factorio\mods`
这个方法不受游戏更新影响(除非游戏更新专门让这个方法失效)，但是要更新mod的时候需要手动移动mod

## 杂项tip
- 【地星不上品质,纯扩张】
- 【插件塔】只能将效果分享给附近的非燃烧设备,并且只有带插件槽的机器才会受到插件塔的影响
- 【传说首先】可以用`Creative`搓一个传说装甲出来 -> 复制箱不停品质回收就行
- 【传说铁箱注意】只要是最终使用的成品,放到一个传说铁箱足够了(比如造出来的传说品质2,传说产能2,收集一箱子完全够了),要是中间产物缓冲用的再多摆箱子,要不就是纯粹的浪费
- 【热量输出】供热塔和核反应堆其实输出热量相同,供热塔燃烧效率高(有能源的地方推荐这个),核反应堆有相连加成(这个造成`2*2`的4个一组效果最好)
- 【核反应堆摆放++双行布局,以及换热器布局】最为有效的摆放方式是对齐双行摆放，数量任意 ; 紧密放置的核反应堆能获得毗连加成，没有加成的核反应堆可驱动四座换热器，每获得100%的毗连加成便可驱动额外的四座换热器
- 【逐日者成就】仅使用太阳能板发电,每小时发电量达一百亿焦耳(10GJ) -> 关键是指定电网内除了太阳能板外**不能有其它发电设施** ; 1小时内产生10GJ电能所需的稳定功率为10GJ÷(60×60s)=2778kW。考虑昼夜交替因素，在新地星上太阳能板的平均发电功率为42kW，即理论上只需铺设67块太阳能板并保持满负载即可解锁本成就
- 【回收机变质物】实际上只有营养物会转化为变质物,其他常见的生物制品如果冻、虫卵、生物研究中心等仍有25%几率被原样返还 ; 回收营养物会产生2.5倍数量的变质物,这与变质物制营养素的情形类似
- 【创造箱设置爪子白名单抓出东西】得把那个创造箱翻到有对应东西的那一页,爪子才能抓出对应的东西!!
- 【亿级科研工厂】采矿产能研究能干到`+271010%`,机器人移速`+2060%`,科研产能到`+900%`,后面的产能加成全部到`+300%`(不过也只到`300%`足够了,别再往后搞了)

## Creative关联法,可跳过太空实现星际物流+任意物流
- 白带,关联带,在任何地方放两个,然后在想要的起点`Shift + 右键点击`,想要的终点`Shift + 左键点击`,这两个地方就连上了,跨星球跨平台也能连
- inventory库存
- 白箱,关联箱,左键点开,中间关联有几个圆盘,能打勾/未打勾,只要这个打勾/未打勾状态是一样的,那这些同状态的白箱就是互联的,一共4个环,每个环可选8个Check Box,也就是一个32位编号,完全够随意使用
- 思考到宇宙真正可怕的地方未必是危险,而是尺度,Factorio中想让 A 地生产的东西出现在 B 地,太空平台已经是夸张的简化手法了,却还是让我觉得繁琐 -> 现实可没有关联箱,"距离"本身还是太过沉重,太空还是太深邃了

## 星球相关
【融冰】这个可以上产能插件,这是在太空平台、雷神星和玄冥星上获取水的主要方式

### 火星,传说工厂主力
丢个核弹就可以炸出一个岩浆洞来(可以摧毁地块变成岩浆地,获得无限资源入口) -> 火星其实是鼓励用来升品质
【岩浆不够】岩浆湖里用工程基座铺一个3格宽的长条路,面对面放一大堆抽取泵,然后管道连出去
【高架铁路可以跨越岩浆】
【生态环境,主要用于地图生成思路】祝融星有三种不同的生态系统： 1.灰烬高原 - 点缀着稀疏的植被和煤矿的高原。这一环境中悬崖和熔岩相对较少，非常适合建设。 ; 2.熔岩盆地 - 充满了蜿蜒的熔岩河流，其中蕴含钨矿，只能使用大型采矿机开采 ; 3.山脉 - 被悬崖地形覆盖的火山，中心有一个大型熔岩池，硫酸喷泉和方解石矿位于此处。
【像悬崖炸药这种一次性消耗物就别拉产线造了,直接创造箱里拿就是了】

### 雷星
【大大方方掏工程基座连岛就得了】工程基座+远程输电塔跨岛供电 ; 雷星其实只需要产出粉瓶,钬板,电磁工厂,与这仨的生产供应无关的全都大大方方掏就得了(比如避雷针,直接Creative掏就得了别搞产线了),每个岛就专门做这三个中的一个 ; 再来一些专门的岛全造蓄电器/传说蓄电器,当供电岛
【废料回收思路】回收废料产生的12种物品中,其中3种只有单一的用途: 1.冰融化成水,**融冰/钬溶液只能在化工厂,不能在低温工厂!!**,这个回收机销毁很快; 2.固体燃料用于和轻油制作火箭燃料,用于发火箭(这个挑个边角的地方搞就行,*别占产线的地方*); 3.钬矿用于和水、石矿制作钬溶液 -> 多余的燃料优先回收机,弄得快,供热塔烧的有点慢
【钬板可以在铸造厂造】可以吃到50%的产能加成 -> 雷星本地摇传说钬板+传说电磁工厂(电磁工厂造电磁工厂然后分解得到原材料) -> 传说钬板拉到火星做传说超导体,即可做传说品质3 + 传说低温工厂 -> 能上产能的一定要猛上产能

### 草星,不上品质,纯扩张
溢出的变质物/种子不仅是回收机,还有丢供热塔燃烧(这个是推荐销毁路径) ; 铜铁矿只能回收机销毁了,两个回收机对着,爪子抓进去那个只要1个速度3就够,剩下全上节能2 , 另一个只放两个节能2降到20%上限即可 【关键是环带】想不明白就上巨大环带,可以优雅处理副产物(种子和变质物)+产线永远不堵
【关于营养素】++的配方为组装机3变质物制营养素(单输入单输出,便捷冷启动) ; 两种果子制营养素(产线特别复杂但产量巨大)
【供热塔的250%效率,处理废弃可燃物】供热塔的效率为250%指的是它能产生其所消耗燃料热值2.5倍的热能 -> 不过供热塔输出恒定,因此因此供热塔与换热器的最优比例固定为1:4 -> 在达到最高温度后，供热塔仍会继续消耗燃料，这使得供热塔拥有一个额外用途：处理废弃的可燃物品(例如句芒星生产的生物制品和变质物，或雷神星上生产的多余固体燃料)
【种植土】沃土对种植地格没有额外加成，而且它们比人造土贵得多，因此，应注意尽量少使用较昂贵的沃土，多用较便宜的人造土就可以了
【玉玛果树和果冻果树的生长】玉玛果树/果冻果树种下5min成熟,产出50个玉玛果/果冻果,相当于每棵树6s一个果,可用来量化

### 太空平台
上高品铸造厂,不要炉子 ; 电力用普通的2台聚变核+8台普通聚变发电机+2台传说低温工厂弄氟酮够了,不需要储液罐,低温工厂的格子存足够了 ; 守船头的话机枪炮塔(造穿甲弹匣)、火箭弹炮塔都传说,磁轨炮用普通和传说交替(防止漏网之鱼),守两侧就是普通品质炮塔即可 ; 要安全就把引擎弄到最少,用1-2个普通的即可(跑得慢,就安全) ; 就炸药在低温工厂造,其他的用那个化工厂就行(能传说就传说)
【*少放激光炮塔*】一排完全够了,摆多了能耗过高了,不要摆第二排激光(比铸造厂耗电还高50%)
【Wiki】与从地面向太空平台运送物资不同，从太空平台向星球投送物资无需花费任何原料(尽管使用了着陆货舱) ; 当推进器因为各种原因在航线中途停车时，太空平台仍将受到行星引力的影响，缓慢地向距离其最近的星球移动(得有推进器之后才会因为熄火缓慢移动)
【太空可获得的资源】氧化星块获取水(融冰)/方解石 ; 金属星块获得铁矿/铜矿 ; 碳质星块获取碳(可转化为煤)/硫磺 ; 煤炭可液化为重油,做石油制品 【**无法获得石矿**】
【使飞船停靠的简单条件】乘客不在场 并且 乘客在场
【**发电**】2台聚变+4台聚变发电机+1台低温工厂,低温工厂长度刚好和聚变发电机一样都是5格,刚好可以塞到空一点的槽里

### 冰星
地下传送带/地下管道的热能消耗要远大于地面铺设的普通传送带/管道 ; 还有插件塔也消耗大量热能
热管不会散失热量到环境中，只有与之相邻的建筑物会消耗热能 -> 热管可以远距传输热力,热管的热能容量是1MJ/度，所以在从500°C升到1000°C的过程中他们可以缓存500MJ的热能，使得其可以作为一种较为节省空间的能量存储设施。不过，温度在“传递”之前需要至少相差1度，因此你无法将其全部升至1000度或者降至500度
所有燃烧设备和供热设施(例如供热塔)不受冻结效果影响
当建筑物与热源相距一格以内，无论是从正面还是对角线方向，它都被视为与热源相邻并能接受供热
【聚变发电最优配置公式】`最优发电机数量 = 2*(反应堆数量 + 所有反应堆享受的毗连加成之和(取整数))`

## 看性能
按`F4`,里面找FPS/UPS相关的开关,应该是第一个 ; FPS是画面帧率,代表显卡压力 , UPS是游戏逻辑更新速度,代表CPU单核压力,默认在60UPS就没问题
地图非必要就少开 -> 最好别用`Creative`里的超级雷达二,用超级雷达那么大的地方完全够了
想要大箱子就用货车车厢 ; 汽车和坦克有额外UPS开销容易变卡 ; 火箭发射井有可能会扰乱太空平台互动并且有1吨上限,实测并不好用

## 记品质,传说相关产线思路
- 【最关键的机制】*液体没有品质*+*无插件时产出品质=输入品质*,因此含有 : 液体+单个固体输入+回收出液体对应的固体(比如进去熔融铜回收出铜板的浇筑轻质框架配方)的配方适合大量造传说,所以++铸造厂配方,并且++高产能、多插槽建筑
- 【品质插件概率】普通品质3,`2.5%` ; 传说品质2,`5%` ; 传说品质3,`6.2%`
- 【*注意*】速度插件会减品质概率
- 需要做传奇的基础材料 : 铁、铜、钢、塑料(其实就是传说煤) -> 不需要传说石头,需要石头混凝土和钢筋混凝土的东西都制造复杂,不如直接在产地硬摇升品
- 如果要刷品质,如果配方能放产能,那就全放产能,只靠回收机升品质是最优解 -> 纯回收机自回收期望是每2727个基础出一个传说,效率极低 -> 除了组装机3型,剩下的铸造厂/生物室/电磁工厂/低温工厂都是全上传说产能3的期望转化率要优于全上传说品质3 ; 但是就算是最差的情况也比回收机纯自回收好得多 -> 用不了产能插件的话,那就老实全上品质插件3吧,这种情况下组装机倍率为154.7 , 铸造厂/生物室为40.8 , 电磁工厂为30.1 , 低温工厂为53.6

### 传说铁 -> 回流的管道在分流器汇合时一定要双输出,要不一条带运力不够 ; 做地下管道和做铁箱采用传说双爪输入减少遗漏避免堵塞
就用铁矿就行(地星),注意品质不够的做成铁箱再分解 ; 火星用浇筑地下管道,先浇筑出管道,各种品质管道+熔融铁造地下管道(注意这里双排铸造厂把熔融铁输出一条在中线供应两端即可,每一边比例:`管道:普通地下:绿色地下:蓝色地下:紫色地下=10:2:1:1:1`,做地下管道采用传说双爪输入减少遗漏避免堵塞),地下管道全部品质回收(不用判传说)出管道和铁板,管道品质不够的回流(回流的管道在分流器汇合时一定要双输出,要不一条带运力不够!),传说的直接拿去分解出传说铁板,铁板传说的直接输出,品质不够的做成铁箱再升一次品再回收,造普通到造紫色比例为`2:1:1:1`(做铁箱采用传说双爪输入减少遗漏避免堵塞),是传说的输出,回收出品质不够的铁板回流再做箱子(这里用一个箱子做缓冲,要不容易堵) -> 【**铁板做铁箱再回收是纯赚**】无额外材料损耗+增加了一次品质判定次数
### 传说煤,塑料,传说轻质框架(高效率),巨额无消耗稳定铜+钢
传说煤用品质矿机+直接进回收机回转弄出传说煤,这样最简单(一条带在大矿机`25/s`的时候,一条带4个大矿机一边2个足够了,太多了会堵塞产线导致停滞,回收机可以多一些,两侧20台品质回收机),传说煤变传说塑料,传说塑料在铸造厂浇筑出传说轻质框架,传说轻质框架回收出传说铜+传说钢+传说塑料,传说塑料回流循环(塑料吃轻质框架300%产能再回收后,相当于催化剂,不消耗了) -> 为什么不先造塑料后循环塑料?:把"升品质的损耗"全部转嫁到最便宜的原料(煤)身上 : 首先回收机每次循环都要损失`75%`的材料,让煤承受这个损失比让塑料承担便宜得多,塑料是二次加工品,回收塑料其实还损失了机器产能 ; 化工厂不需要品质插件了,可以换成产能插件,这是纯赚 -> `LDS`指的就是这条传说产线,Low Density Structure轻质框架
### 传说蓝板(高效率),大量无消耗稳定传说绿板+红板,红板输入(单爪)和绿板输入(双爪)都用传说爪子减少遗漏,便捷停产

### b站刘同学,关于品质的评价
- 本质是将稀有度概念带进自动化游戏 -> 官方思路是工厂扩张存在横向发展和纵向发展,横向发展就是造更多东西,规模扩张 ; 纵向发展是更强的机器和更强的效率 -> 游戏中期玩家会需要考虑横向发展和纵向发展的平衡,游戏后期就变成了主要横向扩张 -> 品质的目的是在大后期为游戏开辟纵向发展道路
- 品质的数值改变了玩家对于产量和空间之间关系的理解,地面上更少的机器就可以产出足量的物资
- 问题: 1.造传说路径高度相似,基本只是配方切换,即会有重复问题; 2.Factorio的品质没有养成元素,传奇全面优于下级导致但凡追求一点强度就只有传奇品质,不存在停在稀有就很合理了的平衡点,所以其实就只有普通、传奇、剩下中间没用的东西这三档
