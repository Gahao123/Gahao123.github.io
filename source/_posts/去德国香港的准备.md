## 欧元相关
去之前预约，但是预约多少欧和能取多少欧似乎无关(最后取了600欧)
拿身份证和银行卡就行，不用签证
换出来的都是200欧的纸币
换回人民币只收纸币，硬币不要。注意纸币不能有太大的破损，要不收不了。

## 去VFS站点：大连北站--沈阳站
VFS离沈阳站很近，到沈阳站比较方便，从东广场出。
回来可以原路，沈阳到大连北有比较晚的车。
从大连北站出来回开发区校区：南广场出来，走地铁站地下通道到大路对面再打车，一定不要坐主动找的打表，公交或网约均可

## 办港澳通行证预约
wx小程序移民局12367 -> 户籍所在地选身份证上的地区 -> 通行证和签注一起办,取证方式建议邮寄 ; 护照和通行证都办的话邮寄是同一个快递寄过来 ; 签注是有自助机"智能签注设备"的,可以直接自己来办签注
物理前往: 高铁直达 ; 飞深圳后高铁香港,深圳到香港只需20m高铁
买境外流量包,去运营商搜"国际",购买后进香港之前去设置 -> SIM卡 -> 开启漫游 ; 还有联通去搜索"跨境语音和短信"打开国际短信
众安za bank,是数字银行,没有线下实体网点一切都在APP进行(在香港下载),入金走跨境支付通很简单,能绑微信支付宝和applePay,但出金只能用wise汇款,实测往内地转1w转到zfb手续费是160转到银联260
开户需要:18岁+ ; 在香港境内 ; 身份证 ; 通行证 ; 内地手机号 ; 和内地手机号绑定的银行卡 ; 需要在主城区内开户 ; 可7*24小时申请,5个工作日内完成审核 ; 手机NFC ; 填的时候职业信息开户目的都如实填写 ; 登记转数快打开,这样在香港银行之间用手机号就能汇款 ; 到等待审核中那里要继续开立投资账户、基金账户两个
【注意】需要买转换插头(英制),搜香港转换插头 ; 酒店在携程上订即可 ; 地铁可以用zfb的出行,城市选香港,是自动换成RMB扣zfb的钱的 ; 付款zfb或wx,带一个人的话一个人刷wx另一个刷zfb就行(wx是小程序搜"地铁"),也可以去带银联的ATM临时直接取出港元不过手续费很贵,只适合急用取几百港元
内卡往港卡免手续费汇:内卡APP首页 -> 转账汇款 -> 跨境汇款 -> 下方"跨境支付通" -> 收款账号+姓名去港卡对应APP找【注,这个只能内卡和港卡同名才能免手续费,且单笔最多1w一天基本上最多3笔】,要转大额就走普通电汇,手续费转越多越划算
众安是自带券商投资功能的,不过得到香港才能办下来
【美股】也是周一到周五,节假日休息 ; 盘中是美东9:30-16:00是主力,对应北京时间夏令时3月-11月是21:30-04:00,冬令时11月-3月是22:30-05:00 ; 盘前盘后夜盘也有但不是主力
汇丰会关户:关户之后汇丰会给一张支票,去香港能把钱提出来,但户头没有且被纳入黑名单 -> 原因:快进快出,应至少存一星期;银行里做一点理财或存款;长期不用,会被认定僵尸户清理
【*注*】就连国内办信用卡是大学生没有稳定收入的话都不好办,信用卡还是工作之后再说
租用地址在美国是很常见的生意。美国人移居海外时也面临同样的问题：在本土没有居所、又没有亲友帮忙，就收不到任何实体邮件。于是很多人把自己的地址拿出来做代收：每天把收到的信件扫描成电子版发给客户，需要时再通过国际快递转寄原件。这类公司很多，随手一搜一大把，比如iPostal1、Anytime Mailbox，月费普遍在10–30美元。
